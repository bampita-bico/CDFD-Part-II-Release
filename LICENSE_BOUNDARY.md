# License Boundary

This Part II release is a scholarly archive. The manuscripts, bibliography,
figures, CSV outputs, metadata, and release documentation are licensed under
CC BY 4.0.

The public CDFD Runtime is separate reusable software infrastructure. It may
use a different software license, such as AGPL-3.0-or-later, without changing
the license of this paper archive.

In practical terms:

- cite this archive for the Part II origins-of-life manuscripts;
- cite Part I for CDFL, the public CDFD framework notation;
- cite the CDFD Runtime separately when engine code is used;
- do not treat the CC BY paper archive as relicensing the engine.
